Dreamstreaming Subtitle Guardian

Automatically checks your movies and episodes for English subtitles, searches via enabled Jellyfin subtitle providers and verifies downloads.

Scheduled task runs daily by default; you can also start it manually.
Turn off only if you specifically want a separate external English subtitle file even when the video already has embedded subtitles.
A search can consume Wyzie/API credits. Default: 25. Set 0 for unlimited searches (watch provider quotas!).
Default: 12. Set 0 for unlimited downloads; test with small limits first.

Run and check results

Full library audit: Running the task manually checks every movie and episode, even when download limits are reached. Missing titles deferred by the limits are prioritized on the next run.

Go to Dashboard → Scheduled Tasks → Dreamstreaming: Verify & download English subtitles. The task runs every 24 hours by default. After a scan, read its summary in the Jellyfin server logs or look for last-report.json in the plugin's data folder.

Required: Install/configure at least one subtitle provider (such as Wyzie Subs or OpenSubtitles), and enable it under the movie/series library subtitle-downloaders settings. This plugin does not bypass provider limits.
